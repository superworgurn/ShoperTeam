## 🇬🇧 English (EN)

### 👋 About Shoper Team

Shoper Team is a team that believes **"When we come together, everything is possible."** We are a group passionate about helping each other, relying on one another, and moving forward together ( •̀ ω •́ )✧

### 🚀 Project Features

- ✨ **Modern Landing Page** with Responsive Design
- 🎬 **Video Slider System** displaying YouTube Playlists (click-to-load facade for maximum performance)
- 👥 **Team Member Profiles** (BioLayout)
- 🌟 **Showcase Section** featuring projects with links to GitHub
- 🐱 **Shopercat Page** — a special page for the team's cats with photo album, videos & playlists
- 🎨 **Beautiful Design** with Blue to Indigo Gradient
- 📱 **Mobile & Desktop Support**

### 🛠️ Technologies Used

- **React** with TypeScript
- **Tailwind CSS** for styling
- **Vite** for build tooling
- **React Router** for navigation
- **YouTube Embed API** for video display (lazy-loaded)

### 🎬 Featured Videos

The project includes a video slider displaying YouTube playlists related to Shoper Team, plus a dedicated **Shopercat** page with cat videos & playlists. Videos use a **click-to-load facade** so no heavy third-party JavaScript is loaded until the user presses play.
